<h1 align="center">STORM SWITCH BOX</h1>

## **О проекте**
STORM SWITCH BOX — многофункциональный комбайн и менеджер библиотеки контента Nintendo Switch для операционной системы Windows. Программа выполняет организацию коллекции игр, парсинг метаданных CNMT/Control NCA, распаковку, сжатие в NSZ (Zstandard), слияние обновлений и DLC (Merge / 1G+1U repacks), конвертацию между NSP и XCI, проверку целостности дампов (NSP Verify), генерацию GP4/PKG, автоматическое переименование по единому стандарту и прямую интеграцию с эмуляторами.

## **Происхождение и форки**
STORM SWITCH BOX — комплексный менеджер библиотеки и контента Nintendo Switch на базе открытых утилит **hactoolnet** (Thealexbarney), **nsz** (NicoBosshard), **NSCB** (JulesHM) и **yanu-cli** с авторской архитектурой графического интерфейса, диспетчером параллельных очередей и интеграцией с эмуляторами.

## **Технологический стек**
- **Языки программирования**: C# (.NET 9.0), Python 3.10+, C++
- **Интерфейс пользователя**: WPF, XAML, Асинхронные очереди с параллельной обработкой
- **Криптографические и системные модули**: hactoolnet, LibHac (.NET), NSCB Core, nsz (Zstandard Block Compression Engine), yanu-cli
- **Парсеры метаданных**: CNMT, NACP, Control NCA, PFS0, HFS0, XCI Cartridge Header

## **Ключевые возможности**
- **Полный цикл работы с форматами**: Конвертация NSP ↔ XCI, сжатие в NSZ/XCZ и обратная декомпрессия без потери метаданных.
- **Слияние обновлений и DLC (Repack)**: Объединение базовой игры, патчей и всех дополнений в единый монолитный установщик (Multi-Title XCI / 1G+1U NSP).
- **Интеллектуальное переименование**: Автоматическое приведение имен файлов к идеальному стандарту: `Название [TitleID] [vВерсия] [Регион] [Языки]` по базе данных.
- **Верификация целостности дампов**: Проверка контрольных сумм NCA, валидация криптографических подписей заголовков и выявление битых ROM-файлов.
- **Прямой запуск в эмуляторах**: Интеграция и автоматический запуск игр в STORM EDEN, Citron, Yuzu, Ryujinx, Suyu с передачей аргументов и профилей.

## **Поддерживаемые платформы и эмуляторы**
- **Операционные системы**: Windows 10, Windows 11 (x64)
- **Поддерживаемые форматы**: NSP, NSZ, XCI, XCZ, NRO, NCA, CNMT
- **Поддерживаемая консоль**: Nintendo Switch
- **Поддерживаемые эмуляторы**: STORM EDEN, Eden, Citron, Yuzu, Ryujinx, Suyu, Sudachi, Torzu, EggNS

## **Установка и запуск**
1. Перейдите в раздел **Releases** на GitHub.
2. Скачайте инсталлятор `STORM_SWITCH_BOX_<версия>_Setup.exe` или архив `STORM_SWITCH_BOX_<версия>.zip`.
3. Установите программу. Все служебные утилиты (`hactoolnet`, `nsz`, `yanu-cli`) уже встроены в дистрибутив.
4. Поместите файл `prod.keys` и `title.keys` в директорию программы для работы с шифрованными файлами.

## **Безопасность и цифровые подписи**
Дистрибутивы подписаны цифровым сертификатом **CN=STORM SOFT, O=STORM EDEN** (SHA-256 Authenticode). Все операции выполняются строго локально на вашем компьютере.
